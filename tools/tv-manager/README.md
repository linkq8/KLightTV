# قائمة التطبيقات — إدارة محلية من الكمبيوتر

تحتاج Python 3.9+ وAndroid SDK Platform-Tools واتصال ADB مصرحًا به. شغّل `start.command` على macOS، أو `start.cmd` على Windows، أو `python3 start.py`. اختر المحاكي أو التلفزيون من القائمة، أو أدخل عنوان IPv4 والمنفذ. للأجهزة التي تتطلب الاقتران اللاسلكي، أتم `adb pair` و`adb connect` أولًا من Platform-Tools ثم اختر الجهاز المتصل.

تُقرأ التطبيقات الموجودة فعليًا لكل جهاز. لا تُنفّذ تغييرات بمجرد الاتصال. حدّد التطبيقات والإجراء، ثم راجع القائمة واضغط «تطبيق التغييرات». زر اختيار خدمات الإعلانات يحدد الحزم المعروفة فقط ولا يطبقها تلقائيًا.

| الإجراء | المعنى |
|---|---|
| تفعيل | تفعيل حزمة موجودة ومعطلة |
| تعطيل | إيقاف التطبيق للمستخدم الحالي مع الاحتفاظ ببياناته |
| تقييد الخلفية | تغيير RUN_ANY_IN_BACKGROUND؛ ليس ضمانًا لإيقاف كل العمليات |
| إزالة للمستخدم الحالي | لتطبيقات النظام الاختيارية المعروفة، مع الاحتفاظ ببياناتها وصورة النظام |
| استعادة آخر عملية | إعادة الحالات المحفوظة للجهاز نفسه، بما فيها التطبيق المدمج المزال |

السجلات المحلية في `~/.urtv-manager/` مرتبطة بمعرّف الجهاز وبصمة نظامه. قد ترفض بعض البرامج الثابتة التعطيل أو الاستعادة؛ تظهر نتيجة كل عملية. لا يوجد root أو حذف من قسم النظام. الحزم المجهولة من النظام والخدمات الأساسية والميكروفون محمية؛ هذا قد يمنع بعض الحزم حتى تُفحص، بدل التخمين من اسم الشركة.

على التلفزيون، شاشة «تطبيقاتي» تدير الإظهار والإخفاء فقط وتفتح تأكيد Android لإلغاء التثبيت؛ الإخفاء لا يعطل الخلفية. تطبيق Android العادي لا يمتلك صلاحية تعطيل جميع حزم النظام. أداة الكمبيوتر لا تثبت خدمة دائمة ولا ترسل قائمة التطبيقات إلى جهة خارجية. إيقاف حزم التحليلات المعروفة لا يثبت توقف كل اتصالات الشركة أو إعلانات خدمات البث.

يمكن التشغيل مباشرة:

```sh
python3 server.py --serial emulator-5554 --adb adb
```

يستمع الخادم على `127.0.0.1` فقط، ويستخدم رمز جلسة محليًا. أغلقه بـ Ctrl+C بعد الانتهاء. لا تشارك رابط الجلسة.
