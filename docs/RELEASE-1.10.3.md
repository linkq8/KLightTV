# KLightTV 1.10.3

- إزالة اسم التطبيق العائم الذي كان يتداخل مع جدول الصلاة، مع الاحتفاظ باسم التطبيق لقارئ الشاشة.
- خانات أرقام كحلية أوضح وحدود خفيفة، مع الخط والأرقام العربية الأصلية.
- تمييز أوسع للصلاة التالية بلون أصفر هادئ وحواف دائرية واسم الصلاة بالأبيض.
- موعد الصلاة والوقت المتبقي داخل بطاقتين متساويتين، بعناوين وأرقام محاذاة في الرئيسية وشاشة التوقف.

الساعة الرئيسية ومواقيت المناطق والانتقال إلى جدول الغد بعد العشاء بنصف ساعة تحتفظ بسلوكها السابق.
