# تثبيت KLightTV على Android TV

1. **الإعدادات ← النظام/تفضيلات الجهاز ← حول**: اضغط **رقم الإصدار / Android TV OS Build سبع مرات** لتفعيل **Developer Mode**.
2. من **خيارات المطوّر** فعّل **Debugging** وتصحيح الشبكة أو **Wireless Debugging** إن توفر.
3. وصّل التلفزيون والكمبيوتر **بالشبكة نفسها**، ثم سجّل **عنوان IP والمنفذ** من إعدادات الشبكة/التصحيح.
4. افتح [المشروع](https://github.com/linkq8/KLightTV) في **Codex أو Claude Code**، واطلب تثبيت التطبيق وتفعيله على ذلك العنوان. وافق على رسالة التصحيح على التلفزيون، وأدخل رمز الاقتران إن طُلب.

**مثال IP توضيحي:** `192.0.2.50` — استبدله بعنوان تلفزيونك الفعلي، وأرفق المنفذ الظاهر في إعدادات التصحيح.

يتولى Codex أو Claude Code تثبيت ملفّي الرئيسية وشاشة التوقف من [الإصدار](https://github.com/linkq8/KLightTV/releases)، ثم إعداد التشغيل حسب ما يسمح به التلفزيون.

**المتطلبات:** Android TV أو Google TV بنظام Android 8+، مع دعم اتصال ADB عبر الشبكة.

## التثبيت بأداة المشروع

تحتاج Python3.9+ وAndroid SDK Platform-Tools. بعد تنزيل المصدر، شغّل من مجلده:

```sh
python3 tools/install.py --connect TV_IP:PORT
```

للاقتران أولًا أضف `--pair TV_IP:PAIR_PORT`. الأداة تسأل عن الرمز، وتطلب موافقتك قبل التثبيت. لتعيين الواجهة وشاشة التوقف أضف `--set-home --set-screensaver`؛ بعض أجهزة الشركات تمنع ذلك. يمكن لـCodex أو Claude Code استخدام `--yes` بعد تفويضه.

تُنزّل ملفات الإصدار وتُطابق بصماتها. ملفات محلية مبنية مسبقًا: `--apk-dir release`. الفحص فقط: `--inspect`. على المحاكي استخدم `--serial emulator-5554`. لا تُحذف تطبيقات ولا تُعطّل واجهة المصنع.

تعرض الأداة مسار نسخة الاستعادة المحلية؛ للاستعادة على الجهاز نفسه:

```sh
python3 tools/install.py --connect TV_IP:PORT --restore SNAPSHOT.json
```

تعيد إعدادات Home وشاشة التوقف فقط، وتحتفظ بالتطبيقات والبيانات. لا تتجاوز الأداة رفض توقيع تحديث أو قيود البرنامج الثابت.
