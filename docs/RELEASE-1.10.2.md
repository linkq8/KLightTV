# KLightTV 1.10.2

يتحول جدول الصلاة إلى مواقيت الغد بعد العشاء بثلاثين دقيقة، مع عنوان «مواقيت الصلاة غدًا» واليوم والتاريخ والمنطقة. عند منتصف الليل يصبح العنوان «مواقيت الصلاة اليوم» للتاريخ نفسه، ثم يتحدث الجدول يوميًا بالطريقة ذاتها.

الجدول وموعد الصلاة التالية يستخدمان مواقيت المنطقة وتصحيحاتها نفسها. يشمل التغيير الرئيسية وشاشة التوقف، مع دعم الانتقال بين الشهور والسنوات والسنة الكبيسة ويوم الجمعة.
