# المدن والمواقيت والمظهر والتنبيهات

- اختيار دولة ثم مدينة، والبحث عند الطلب عبر Open-Meteo/GeoNames. لا تُحمّل قاعدة مدن أو مكتبة صور عالمية. يحفظ التطبيق المدينة المختارة وإحداثياتها ومنطقتها الزمنية فقط.
- الحساب دون شبكة بمكتبة Adhan Java 1.2.1، دون اعتماديات إضافية أو خدمات. تُختار الطريقة تلقائيًا للكويت والسعودية ومصر والإمارات وقطر وباكستان وبنغلادش وسنغافورة وأمريكا/كندا، ورابطة العالم الإسلامي لباقي الدول. يمكن تغيير الطريقة والعصر الحنفي/الجمهور. هذه افتراضات قابلة للتعديل وليست اعتمادًا رسميًا لكل مسجد أو دولة.
- الكويت: تُفضّل سجلات العجيري المؤرخة للمناطق ذات الفرق الموثق. الخيران تحسب بالإحداثيات؛ لا يوجد فرق رسمي ثابت مثبت لها في التطبيق. أي طريقة أخرى تُعرَض باعتبارها حسابًا، لا نسخة من جدول رسمي.
- الحساب يراعي المنطقة الزمنية وDST. عند تعذر الزوايا في العروض العليا تستخدم المكتبة سُبع الليل. المواقع القطبية التي لا يمكن فيها استخراج جدول متسلسل صالح تُعرض دون مواقيت أو تنبيهات مخمّنة، ويلزمها جدول محلي معتمد. بعض جداول العشاء بعد منتصف الليل غير مدعومة بعد.
- أم القرى: 90 دقيقة بعد المغرب، و120 دقيقة في الشهر التاسع بحسب تقويم Umm al-Qura المدمج في Java؛ الإعلان المحلي قد يختلف. هذا حساب وليس تغذية مباشرة من الجهة الرسمية.
- الطقس كل 30 دقيقة أثناء ظهور الواجهة، مع قراءة محفوظة للمدينة الحالية. فشل الشبكة لا يوقف الحساب المحلي. ذاكرة الطقس على القرص تُستبدل ولا تتراكم لكل المدن. سجلات العجيري محدودة إلى نافذة 90 يومًا.
- فاتح/داكن/تلقائي في التطبيقين، بما فيها الرئيسية وشاشة التوقف وشاشات الأدوات. طبقات لونية ثابتة دون تمويه متحرك. لا يُغيّر التطبيق مظهر إعدادات Android أو تطبيقات البث الخارجية.
- التنبيه عند الأذان، ويمكن إضافة تنبيه قبله بـ5 أو10 دقائق. لا صوت، لا إيقاظ للشاشة، لا إيقاف للمشاهدة. نافذة غير قابلة للمس أعلى اليمين لمدة7 ثوانٍ. موعد AlarmManager واحد فقط؛ يعاد جدولته بعد كل حدث وعند تغير الوقت/الموقع أو إعادة التشغيل. لا خدمة دائمة للتنبيه.
- تتطلب التنبيهات إذن الظهور فوق التطبيقات والمواعيد الدقيقة. بعض تطبيقات الفيديو المحمية أو أجهزة الشركات تمنع النوافذ العائمة؛ لا يمكن ضمان ظهورها فوق كل تطبيق.
